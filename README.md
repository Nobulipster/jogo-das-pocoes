## Introdução

<a href="#índice"><img align="right" width="15" height="15" src="./docs/up-arrow.png" alt="Voltar para topo"></a>

O objetivo deste projeto é desenvolver um jogo digital utilizando exclusivamente  introduzir HTML, CSS e JavaScript, aplicando osconceitos estudados na disciplina, como estruturação de páginas, estilização, manipulação do DOM, tratamento de eventos e lógica de programação. Esse projeto será utilizado como Atividade Prática na disciplina GAC116 - Programação Web da Universidade Federal de Lavras (UFLA).

No Jogo das Poções, o jogador assume o papel do Mestre das Poções do Rei. Todos os dias, o Rei surge no seu laboratório com problemas inusitados — desde calvície mágica até dores de estômago causadas pela falta da visícula biliar. Assim, o jogador deve usar o seu conhecimento (e um pouco de dedução) para combinar os ingredientes certos no seu caldeirão e criar a poção perfeita para cada situação. *Mas cuidado!* Misturar as coisas erradas pode piorar ainda mais a vida do Rei.

## Instruções de Como Jogar

<a href="#índice"><img align="right" width="15" height="15" src="./docs/up-arrow.png" alt="Voltar para topo"></a>

### Como Jogar:

1. **Analise o Problema:** A cada rodada, o Rei apresentará um problema. Leia com atenção para descobrir do que ele precisa.

2. **Estude os Ingredientes:** No topo da sua tela, você tem uma prateleira com 10 ingredientes mágicos. Passe o mouse sobre eles para ler suas propriedades e dicas do que eles podem fazer.

3. **Faça a Poção:** Escolha exatamente 2 ingredientes que você acha que resolvem o problema e coloque-os no caldeirão (você pode clicar neles ou arrastá-los).

4. **Descubra o Resultado:** O caldeirão fará a mistura. Se a poção criada for a certa para o problema, você ganha pontos.

### Regras e Pontuação:

* **Vitória:** Toda vez que você resolve um problema corretamente, você ganha 1 Ponto de Sucesso num medidor de Problemas Resolvidos. Acumule 3 Problemas Resolvidos para vencer a partida e não ser destituído de suas funções pelo Rei!

* **Game Over:** Se a poção estiver errada e não resolver o problema, você ganha 1 Ponto de Falha num medidor de Problemas Não Resolvidos. Se atingir 3 Problemas Não Resolvidos, sua licença de alquimista é revogada e você é demitido!

* **"Ir para Casa":** A vida de alquimista está muito estressante? A qualquer momento você pode clicar em "Ir para Casa". Mas atenção: isso fará você abandonar o Rei, resultando em um Game Over instantâneo (afinal, você deixou os problemas de lado para tirar uma soneca!).
